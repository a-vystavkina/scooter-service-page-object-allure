# Sprint_6: UI-автотесты для учебного сервиса «Яндекс.Самокат»

Финальный проект 6 спринта курса «Инженер по тестированию: от новичка до автоматизатора» (Яндекс Практикум).

Автотесты покрывают сценарии учебного сервиса https://qa-scooter.praktikum-services.ru/

## Что проверяют тесты

**Раздел «Вопросы о важном» (`tests/test_faq.py`)**
- Клик по стрелочке у каждого из 8 вопросов открывает соответствующий текст ответа. Отдельный тест на каждый вопрос через параметризацию.

**Заказ самоката (`tests/test_order.py`)**
- Позитивный сценарий заказа через кнопку «Заказать» вверху страницы (два набора данных).
- Позитивный сценарий заказа через кнопку «Заказать» внизу страницы (два набора данных).
- Клик по логотипу «Самоката» ведёт на главную страницу.
- Клик по логотипу Яндекса открывает в новой вкладке главную страницу Дзена через редирект.

## Структура проекта

- `locators/` — локаторы элементов страниц (`main_page_locators.py`, `order_page_locators.py`)
- `pages/` — Page Object классы (`base_page.py`, `main_page.py`, `order_page.py`)
- `tests/` — файлы с тестами (`test_faq.py`, `test_order.py`)
- `data.py` — URL, тестовые данные для заказа и тексты вопросов и ответов
- `conftest.py` — фикстура с драйвером Firefox
- `allure_results/` — результаты прогона для Allure
- `allure_report/` — сгенерированный Allure-отчёт
- `requirements.txt` — зависимости проекта

## Технологии

- Python 3
- Pytest
- Selenium WebDriver (браузер Mozilla Firefox)
- Allure (allure-pytest)
- Page Object Model

## Как запустить

1. Установить Mozilla Firefox.
2. Создать и активировать виртуальное окружение:
   ```
   python -m venv venv
   source venv/Scripts/activate
   ```
3. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Запустить тесты с записью результатов для Allure:
   ```
   python -m pytest -v --alluredir=allure_results
   ```
5. Сформировать и открыть Allure-отчёт:
   ```
   allure serve allure_results
   ```
